\section*{Extraits de code du cœur métier}
\phantomsection\label{ann:code-metier}
Briques les plus représentatives de la logique du module tournois, exploitées au chapitre~2 et testées comme le décrit la partie~\ref*{sec:tests-unitaires}. Le contrat commun des formats est défini par l'interface \texttt{GenerateurFormat}, que chaque format implémente, une fabrique associant le type de phase à la bonne classe. La logique de classement départage les égalités par confrontation directe puis par une cascade scalaire.
