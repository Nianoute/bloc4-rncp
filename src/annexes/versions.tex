\section*{Objet de l'annexe}
Cette annexe présente l'historique des versions du projet, obtenu via la commande \texttt{git log --oneline --decorate}. Les commits suivent la convention Conventional Commits (\texttt{feat:}, \texttt{fix:}, \texttt{chore:}, \texttt{docs:}, \texttt{test:}), et les versions livrées sont identifiées par des tags sémantiques.
