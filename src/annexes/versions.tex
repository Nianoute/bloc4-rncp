\section*{Objet de l'annexe}
Cette annexe présente l'historique des versions du projet, obtenu via la commande \texttt{git log --oneline --decorate}. Les commits suivent la convention Conventional Commits (\texttt{feat:}, \texttt{fix:}, \texttt{chore:}, \texttt{docs:}, \texttt{test:}), et les versions livrées sont identifiées par des tags sémantiques. Elle est référencée à la \hyperref[sec:versions-git]{partie~\ref*{sec:versions-git}}.

\section*{Journal des commits taggés}
L'extrait ci-dessous illustre la discipline de versionnement du dépôt. On y voit les tags sémantiques (\texttt{v0.1.0}, qui marquait le prototype fonctionnel, puis \texttt{v0.2.0}) portés sur \texttt{main}, chaque fonctionnalité étant intégrée par une branche dédiée (\texttt{feat/*}) fusionnée dans \texttt{dev} puis dans \texttt{main}. Les versions ultérieures (\texttt{v0.2.1} et \texttt{v0.3.0}) suivent la même convention, comme le récapitule le tableau des versions au chapitre~4. Cette organisation rend la traçabilité des évolutions immédiate.
