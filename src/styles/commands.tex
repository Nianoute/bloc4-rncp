% Note en italique rouge : marque un point non encore réalisé et propose la
% bonne pratique de développement à adapter une fois le code écrit.
% À remplacer par le contenu réel (capture, extrait, chiffre) le moment venu.
\newcommand{\todo}[1]{{\normalfont\color{red}\itshape[TODO : ~: #1]}}

% Neutralise, pour la prochaine section numérotée uniquement, le saut de page
% inséré automatiquement avant chaque section. La section enchaîne alors dans
% la continuité de la précédente, ce qui évite de laisser une page à moitié
% vide en fin de section.
